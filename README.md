#  Car Rental App

Application de gestion de location de véhicules (Voitures, Camions, Motos) réalisée en Python avec une interface graphique Tkinter.

## Fonctionnalités

- Gestion de la flotte: Ajout de véhicules (Marque, Modèle, Catégorie, Prix).
- Gestion des clients : Enregistrement des clients avec vérification de l'âge et du permis.
- Système de Location :
  - Vérification de la disponibilité.
  - Règles métier (Ex: Pas de camion pour les -25 ans).
  - Calcul automatique du coût total.
- Interface Graphique (GUI) : Tableau de bord visuel et formulaires simples.
- Données de démo: Chargement automatique d'un jeu de données au démarrage.
